# A 股实时行情

[market.py](../vnpy/autonomous/market.py) 提供只读的 A 股实时行情拉取，用于在把策略交给
真实盘口之前核对「信号说要买」和「这个标的今天到底能不能交易」。它不下单，也不
把行情快照当作成交回报。

## 行情查询

```bash
# 查询指定代码
python -m vnpy.autonomous quotes --symbol 600519 --symbol 601318

# 查询配置文件里已装配的策略标的
python -m vnpy.autonomous quotes

# JSON 输出，便于值守脚本消费
python -m vnpy.autonomous quotes --symbol 600519 --json
```

不带 `--symbol` 时，命令读取 `app_settings.CtaStrategy.strategies` 中的 `vt_symbol`，
这正是 `promote --apply` 写回的那批条目，因此可以直接用来做上盘前的标的核对。

## 代码到行情标识的映射

东财接口要求 `secid` 形如 `市场号.代码`：上交所 `1`，深交所 `0`。这个前缀属于交易
所而不是代码本身，**不能从代码数字猜**：`000001` 在深市是平安银行，在沪市是上证指数，
猜错会静默漏掉一行。`resolve_secid` 对 `6` 开头的代码给 `1.` 前缀，其余给 `0.` 前缀，
已带 `.SH`/`.SZ`/`.SZSE` 后缀的按后缀处理。批量查询时按调用方传入的 `secid` 原样回
填，不按代码反推市场。

## 价格标度

接口返回的价格和百分比都是以 100 为标度的整数（分）。`f43` 原值 `141027` 对应
`1410.27` 元。`PRICE_SCALE` 与 `PCT_SCALE` 集中定义在模块顶部，不按标度还原会把所有
价格放大 100 倍。

字段含义：`f43` 最新价、`f60`/`f18` 昨收、`f170`/`f3` 涨跌幅、`f169`/`f4` 涨跌额、
`f86`/`f124` unix 秒级时间戳。

## 失败处理

单标的查询在交易所没有该标的时抛 `ValueError`，配置里写错代码会直接报错而不是返回空
行。批量查询把失败的条目放进 `QuoteError` 与成功条目一起返回，组合里有一个代码退市
不会让整份清单失败。网络被瞬时掐断时最多重试三次，间隔递增；仍失败则以 `ValueError`
向上抛。

## 数据源边界

行情来自东财公开推送接口，无需数据服务账号。它替代不了交易所行情源，也只覆盖 A 股。
下单仍然需要 CTP 或券商账号——这个模块只回答「现在是什么价」，不回答「成交了没有」。

## 批量拉日前复权日线

`stocks.fetch_daily_bars` 走 `push2his` 的 kline 路径，与上文的 `push2` 快照主机是不同的
 主机，可用性也不同。实测记录（2026-11-13）：

- kline 直连持续返回连接重置；两个加速网关与 `down.nigx.cn` 均可用，但同一时段 `jsnzkpg4.pages.dev` 对全部代码返回 520、`seep.eu.org` 返回 503，即上游临时故障而非代码问题。
- 判据：对 `1.600519` 请求 2023-01-01 起 3 年日线，响应体含 `"klines"` 才算可用。三条路同时不返回时，批量任务应当停下等恢复，而不是把整个清单刷成失败——继续重试只会消耗限流预算。
- 单只耗时约 8 秒（`MIN_REQUEST_GAP_SECS = 3.0` × 每 5 年一次窗口请求）。568 只非 ST 候选全量拉取约需 80 分钟。
- 磁盘缓存 TTL 24 小时，落在 `.vntrader/stock_bars/<secid>_101.csv`。批量任务续跑靠这个目录：已缓存的跳过，失败的下轮重试。

拉下来的数据只覆盖 77 只拥有连续 600 根以上日线的股票，样本足够做折叠验证，但远不是
全市场。把结论当成 77 只的结论，不要当成 A 股的结论。
